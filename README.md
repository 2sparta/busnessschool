# 🏛️ Empire Business School — Сайт бізнес-школи

Сучасний, адаптивний вебсайт бізнес-школи з презентацією курсів, тарифами, умовною покупкою та персональним інтерактивним кабінетом студента.

Розроблено на **Next.js (App Router)**, **Tailwind CSS** та **PostgreSQL / Drizzle ORM**. Підтримує як повнофункціональний серверний деплой на **Vercel**, так і **100% статичний хостинг на GitHub Pages**.

---

## ⚡ Як захостити сайт на Vercel (Найпростіший і найшвидший варіант)

Сайт тепер повністю готовий до деплою на Vercel «з коробки». Наявність або відсутність бази даних більше не блокує білд:

1. **Завантажте код на GitHub**:
   ```bash
   git add .
   git commit -m "fix: make database optional during build for seamless Vercel deployment"
   git push
   ```

2. **Імпортуйте проєкт у Vercel**:
   - Перейдіть на [vercel.com/new](https://vercel.com/new)
   - Оберіть ваш репозиторій (`busnessschool`)
   - **Framework Preset**: залиште `Next.js`
   - **Root Directory**: залиште за замовчуванням (`./`)
   - Натисніть **Deploy**!

3. **Готово!**
   - Білд на Vercel пройде за ~30 секунд і сайт одразу відкриється за посиланням `https://...vercel.app`.
   - **Умовна покупка та кабінет працюють без додаткових налаштувань**: студент може оформити тестову заявку, відкрити кабінет, перемикати тарифи («Старт», «Менторство», «VIP»), переглядати розклад живих зустрічей і дивитися відеолекції.
   - *(Опціонально)*: Якщо ви пізніше захочете підключити реальну базу даних PostgreSQL (наприклад, Vercel Postgres, Neon або Supabase), просто додайте змінну `DATABASE_URL` у вкладці **Settings -> Environment Variables** вашого проєкту на Vercel. Якщо змінної немає — сайт автоматично працює в демонстраційному режимі.

## 🚀 Як захостити на GitHub (GitHub Pages)

### Спосіб 1: Автоматичний деплой через GitHub Actions

У проєкті вже налаштовано готовий workflow [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml).

1. **Завантажте код у ваш репозиторій**:
   ```bash
   git push origin main
   ```

2. **Увімкніть GitHub Pages у налаштуваннях репозиторію**:
   - Відкрийте репозиторій на GitHub -> **Settings** -> **Pages**
   - У розділі **Build and deployment** -> **Source** оберіть:
     👉 **GitHub Actions**

3. **Сайт з'явиться за адресою**:
   `https://<ваш-username>.github.io/<назва-репозиторію>/`

---

### Спосіб 2: Ручний білд статичної версії на комп'ютері

```bash
# Встановіть залежності
npm install

# Згенеруйте статичну версію для GitHub Pages
node scripts/build-gh-pages.mjs
```

Готовий результат буде у теці `./out`.

## 💡 Особливості кабінету та покупки

- **Умовна покупка**: не вимагає банківських карток чи оплати. Після введення імені та email користувач одразу потрапляє до свого кабінету.
- **Особистий кабінет (`/cabinet`)**:
  - **Для тарифів «Менторство» та «VIP»**: показує розклад щотижневих онлайн-зустрічей (щосереди о 18:30 за Києвом), активне посилання на кімнату Google Meet/Zoom та інформацію про ментора.
  - **Для тарифу «Старт»**: пояснює, що навчання проходить самостійно без щотижневих зустрічей.
  - **Перемикач тарифів у шапці кабінету**: дозволяє клієнту або вам протестувати, як кабінет виглядає для всіх трьох тарифів без повторного проходження форми.
  - **Інтерактивний трекер прогресу**: зберігає відмічені уроки в пам'яті браузера.
  - **Відеобібліотека**: інтегровані відеоуроки від кураторів.
